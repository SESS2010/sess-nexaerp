  generic viewer for all ten company reports — columns, rows, totals and
  coverage come from the server; drill-through by row (`group`) or measure

  upload, period, reason → `POST /from-import`; list by stage; detail shows the
  three-person ceremony table, Confirm value (Accounts, `verify`) and Authorize
  and post (TD, `approve`) with reason, version and idempotency key; lines with
  posted lot / serial / FIFO layer ids. Warns before the server does when the
  signed-in person already took an earlier step. Manager's item 3.

  next step (movements exist, period loaded, same employee twice, authority /
  assignment, company / import, version, command context); the server's
  sentence is always shown underneath. Also fixed a pre-existing slip where the
  `version` word-boundary regex held literal backspace bytes and never matched.

  `downloadErrorWorkbook`, `ImportResult` now carries `InvalidRows` /
  `NotImportedRows`; the import bar offers "⬇ errors.xlsx" whenever rows were
