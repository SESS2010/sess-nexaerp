# SESS.NexaERP.Application

Application interfaces and request/response contracts.

Find the feature folder (`Purchase/`, `Stores/`, `Masters/`, `Tracking/`, `Outbox/`, `Reporting/`), then locate implementations in Infrastructure and callers in Api/Endpoints. `Common/`, `Authorization/` and `Identity/` define shared context.

See [R1 code map](../../docs/CODE-MAP.md) for screen, API, service, table, migration and test links, and the [fresh database runbook](../../docs/installation/go-live-fresh-database-runbook.md) for setup. No revision-named files are renamed before go-live.
