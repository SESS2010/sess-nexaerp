## Selected evidence-pipeline architecture

Option A is non-circular because readers calculate facts only from persisted state and exact keys; the adapter maps actual typed fields before reading oracle expectations; and the verifier alone calculates PASS. It is least-privilege because readers expose bounded projections only. It scales because work is operation/company scoped. It is testable because each boundary accepts independent raw fixtures.

Option B is rejected: a database-produced envelope would duplicate oracle knowledge in SQL or accept caller metadata, increasing coupling and self-attestation risk. A signature cannot make expected-derived values independent.
