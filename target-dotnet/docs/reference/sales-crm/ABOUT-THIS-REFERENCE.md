# SESS Sales CRM V3.2: reference copy

A Google Apps Script web app built by SESS staff for sales. It covers:
- enquiries, offers with line items and terms, revisions and FY numbering;
- stages and weighted pipeline, follow-ups, 10-day automatic reminders, and a communications log;
- a management dashboard.

The Technical Director made it the reference for **Track D** (master requirements
`docs/requirements/SESS-NexaERP-Master-Requirements-v2.md` §2.D, §5.4).

It is **documentation only**. It is not built, run or deployed from this repository.
