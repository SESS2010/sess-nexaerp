# Vendor manual assessments

The Production Manager exception in Vendor Rating Specification section 8 is restricted to a GRN whose retained ReceivedByEmployeeId is that employee. A role label alone does not establish receipt ownership. The service resolves an actual eligible assignment and that role's page permission (or an explicit employee page grant); a Production Manager grant cannot confer QC's unrestricted receipt scope on a dual-role employee.

The endpoint retains the GRN version, supplier and PO from the actual receipt, resolved employee/role assignment, server time and reason. Corrections append an explicit successor revision; previous scores remain available. No combined vendor rating is exposed until the five automatic dimensions are bound to approved source rules.

Frontend: use GET `/api/v1/quality/vendor-manual-assessments/receipts?page=1&pageSize=50` for the permitted receipt selector. QC sees company-scoped eligible receipts; Production Manager sees only receipts they personally received. POST `/api/v1/quality/vendor-manual-assessments` with GRN ID/version, optional latest assessment ID to supersede, the three scores, reason and idempotency key. GET `/for-receipt/{goodsReceiptId}` returns history within the same role/receiver scope. Both roles use the manual-assessment page's View/Create permissions. The separate QC source-evidence reader retains its original permissions and QC-only service authority.

Same-key replay retains the original result; changed payload, stale source or competing correction conflicts. Reversed receipts cannot receive a new assessment. The database rechecks the receiving-manager condition under the GRN lock, using the governed command's actual actor. Later QC corrections do not erase the original manager assessment or its authority.
