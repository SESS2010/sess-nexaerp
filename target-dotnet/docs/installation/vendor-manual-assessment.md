# Vendor manual assessments

QC Manager records Technical /15, Response /5 and Overall /5 per finalized normal GRN. The endpoint retains the GRN version, supplier and PO from the actual receipt, resolved employee/role assignment, server time and reason. Corrections append an explicit successor revision; previous scores remain available. The API deliberately exposes no combined vendor rating until the five automatic dimensions are bound to approved source rules.

Frontend: QC first reads the narrow receipt selector at `/api/v1/quality/vendor-rating-evidence/receipts`. POST `/api/v1/quality/vendor-manual-assessments` with GRN ID/version, optional latest assessment ID to supersede, the three scores, reason and idempotency key; GET `/for-receipt/{goodsReceiptId}` returns company-scoped history. QC Manager page View/Create permissions apply. Same-key replay retains the original result; changed payload, stale source or competing correction conflicts. Reversed receipts cannot receive a new assessment.

Install effects: one private assessment table and governed functions/guard; two page/permission configuration rows; zero operational assessment or stock rows. No bill-line or item rating field. Unused package rollback is supported; retained assessments prevent rollback. Installer verifies and repairs private privileges and checks the append guard.
