# Vendor rating source evidence

GET `/api/v1/quality/vendor-rating-evidence/receipts` supplies a paginated list of eligible GRN IDs/versions, numbers, vendor IDs and receipt timestamps. It retains the Stores GRN detail restriction and excludes drafts/reversed receipts. GET `/api/v1/quality/vendor-rating-evidence/{goodsReceiptId}` gives the selected company QC Manager current evidence for a finalized, unreversed normal GRN. The existing QC page View permission applies. This read-only view does not save a rating or change inventory.

Quality remains per GRN line and UOM. It uses the latest finalized QC revision per lot, accepted quantity and identifiable live concessions. A reversed concession contributes zero even when its original row still says APPROVED. Missing QC or unresolved discrepancy produces no score. Retained quantities must reconcile before any result is returned.

Delivery uses the retained PO comparison line ISO committed date and receipt date in the configured company time zone. Missing dates remain unscored. The shipment score is available only when all lines share a committed date; mixed-date aggregation requires an approved rule. Unlike units are never averaged into a quality total.

Record IDs, source versions, rule version, local date/time zone and a deterministic source fingerprint accompany results. This is a current evidence view, not an immutable historical rating.
