# R1.1 opening-stock and stock-count entry (15-31 October)

Design only; no R1 code. Estimate 6-9 engineering days including barcode integration,
permission/transaction tests and browser UAT, with shared barcode lookup reused.

Add a company-bound rack-first count workspace: choose warehouse/rack, scan or find
item/bin/lot, enter quantity and save versioned draft lines. Scanner Enter selects
and focuses quantity; it never submits, posts or silently adds quantity. Preserve
item, UOM, tracking policy, serial/lot and physical rack references. Show duplicate
serials, uncertain scans and invalid precision before review. Save/reopen drafts,
record who counted and when, and retain changes instead of overwriting history.

Inline New rack/bin or New item opens the existing governed master flow only for
its owner's grants. Missing-item drafts remain blocked until item approval; creating
a master cannot create stock. Do not expand store-counter grants to item approval.
Separate physical count from Accounts' ex-tax unit valuation. Reuse the three-actor
ceremony: Stores Manager confirms count, Accounts Manager values, TD authorizes;
three different employees, version checks, reasons and retained evidence. One
idempotent, atomic posting per company ceremony; concurrent/replayed authorization
cannot double-post. Reject if any prior stock movement exists. No GRN shortcut.

After go-live, opening-stock entry is read-only for an already-posted company.
The same draft-count UI then supports stock checks; discrepancies go through the
existing governed stock-adjustment process and an open inventory period, never a
second opening balance. Barcode lookup and rack/item/lot label printing remain
shared R1.1 features; this estimate excludes building a separate barcode subsystem.
Export the existing opening-stock v2 workbook for review/compatibility, preserving
text codes and lineage. Tests cover cross-company rejection, unauthorized inline
create, serial/lot errors, stale drafts, three-actor separation, rollback and retry,
plus keyboard scanner focus on the supported browsers/printers.
