# Load Test Plan

Approved tools: k6, JMeter or equivalent.

Progressive targets:

- 1,000 concurrent users
- 5,000 concurrent users
- 10,000 concurrent users
- 25,000 concurrent users
- 50,000 concurrent users
- 100,000 concurrent users
- 300,000 concurrent sessions only if commercially required

Do not claim capacity without reproducible scripts and measured evidence.

Workflows to test:

- Login/token refresh
- Dashboard
- Customer/vendor/item search
- PR creation and approval
- RFQ/quote/comparison/PO
- GRN and stock lookup
- Reservation and material issue
- File upload/download
- Reports and exports
